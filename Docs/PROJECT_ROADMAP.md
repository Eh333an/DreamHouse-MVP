# DreamHouse MVP — startup checklist

## Milestone 0 — source handoff
- [x] Initialize GitHub repository and README.
- [ ] Upload the Unity project ZIP to the repository.
- [ ] Confirm the archive is committed and downloadable.

## Milestone 1 — Unity import and compile
- [ ] Open in a compatible Unity Editor with Android modules installed.
- [ ] Run editor setup and create/verify a playable scene.
- [ ] Resolve compiler errors and missing references.
- [ ] Verify both character variants and all three rooms.

## Milestone 2 — device test
- [ ] Configure Android package identifier and orientation.
- [ ] Build a debug APK.
- [ ] Install on the target Android phone.
- [ ] Test touch input, camera, wardrobe, interactions, mission progress, and save/load.

## Milestone 3 — release candidate
- [ ] Fix device-specific defects and performance issues.
- [ ] Build a signed release APK.
- [ ] Record Unity version, build number, package ID, and test results.

**Important:** Repository initialization is not a successful build. No APK exists until Unity finishes a build and the resulting file is tested.
